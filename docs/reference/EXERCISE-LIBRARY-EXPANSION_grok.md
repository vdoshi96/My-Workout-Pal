# Exercise library expansion YouTube candidates (Grok research)

## Purpose

This file records candidate YouTube demonstrations for the 108 expansion movements in [`EXERCISE-LIBRARY-EXPANSION.md`](EXERCISE-LIBRARY-EXPANSION.md). Use it as research input for later private curation. It is not an approved seed and it does not change production video status.

Candidate links and approved catalog demonstrations remain separate states. An `approved_pair` still requires exactly two unique, eligible, fully watched demonstrations under [`YOUTUBE-CURATION.md`](YOUTUBE-CURATION.md).

## Research boundary

The following facts apply to every row in this file:

- Researcher: Grok 4.6.
- Research date: August 27, 2026.
- Discovery: `yt-dlp` search, then YouTube Data API `videos.list` for title, channel, duration, privacy, and embeddable status.
- Video status: `not_started`.
- Approval state: not approved.
- Fully watched: no. The researcher did not watch any video from start to finish.
- Syndication: unverified. API search did not use `videoSyndicated=true`, and no scoped `youtube-nocookie` embed probe was recorded.
- Do not copy these IDs into the production seed until a human completes a full watch, exact-variation review, and scoped embed verification.

Prefer videos that demonstrate one exercise, are 30 seconds to 6 minutes long, use English, and come from two distinct channels. Reject Shorts, compilations, follow-alongs, challenges, and wrong equipment when you review.
